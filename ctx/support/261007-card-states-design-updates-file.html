Kanvy — card states workspace

Each section renders the same matrix of card states (kind × interaction × view mode) at canvas zoom 1. “Current” mirrors the app; “concept” starts identical and is styled by its own block (style#concept-css). Hover/selected/editing cells are forced via .is-hover/.is-focus/.is-focus-visible; every card is also live (hover it, type in it).

Light mode — current

mirrors src/ — do not edit

Standard view mode

Border = the card’s own accent color (default gray).

Accent colors (standard view mode)

Every user-selectable accent (ColorKey). Gray is the default and the one theme-dependent accent.

Task view mode

Border = task status; non-tasks are dimmed with a gray border.

Recency view mode

Border = age band (≤1d lime, ≤1w amber, ≤1mo orange, older coral) plus a relative-time label.
